# 블루피스 테스트 홈페이지 운영 규칙

## 경로와 분리 기준

- 운영 홈페이지: `/`
- 테스트 홈페이지: `/TEST`
- 테스트 전용 화면은 `app/TEST`, `components/test-site-homepage.tsx`, `lib/test-site-data.ts`에 둔다.
- 테스트 폼은 브라우저 상태만 사용하며 API, Supabase, 알림 서비스로 제출하지 않는다.
- 마케팅 최초 유입 기록은 `/TEST`와 그 하위 경로에서 만들지 않는다.
- 검색엔진에는 `/TEST`를 `noindex, nofollow`로 알린다.

## 운영 반영 방식

테스트 화면 전체를 운영 화면에 복사하지 않는다. 사용자가 운영 반영을 명시적으로 승인한 항목만 골라 `app/page.js` 또는 운영 문의 흐름에 적용하고, 각 항목을 다시 검증한다.

## 기준 버전과 되돌리기

- 테스트 페이지 추가 전 운영 기준 태그: `production-baseline-before-test-2026-10-17`
- 테스트 변경만 되돌릴 때는 테스트 페이지 추가 커밋을 `git revert <commit>`으로 되돌린다.
- 기준 태그로 운영 전체를 강제로 덮어쓰지 않는다. 그 사이 생긴 다른 운영 변경을 잃을 수 있기 때문이다.

## 자료 확인이 더 필요한 항목

- 체험 외 과정별 정확한 수업 시간과 횟수
- 과정별 연령 및 선행 자격 조건
- 풀장 입장료와 장비 렌탈료의 실제 금액
- 강사별 자격 번호, 발급 기관, 지도 경력
- 개인정보 보관 기간과 상세 처리방침 URL
- 취소 및 일정 변경 기준
- “대구·경북 최대”, 누적 수강생, 자격 발급률 같은 수치의 산정 근거와 기준일
- 두류풀장 공사 및 이용 가능 상태의 최신 확인일
